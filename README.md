# Expert System – Illegal Mining Pollution Risk Assessment

## Overview
This project is an **expert system** designed to assess the overall pollution risk caused by illegal mining in various communities.  
It combines rule-based logic with modern web development technologies to provide real-time, user-friendly risk assessments.

---

## System Description
The system:

- Uses **Prolog** to define and execute rules and facts for pollution risk evaluation.
- Implements a **Flask (Python)** backend to handle API requests and process data.
- Features a **React.js** frontend for interactive user input and clear visualization of results.

---

## Features
- **Community Pollution Risk Assessment** – Input community-specific data and get a calculated risk score.
- **Rule-based Decision Making** – Powered by Prolog for deterministic and explainable logic.
- **REST API** – Flask backend connects the Prolog inference engine with the frontend.
- **Modern UI** – Built with React for an interactive and responsive interface.
- **Multi-language Stack** – Integrates JavaScript, Python, and Prolog seamlessly.

## Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Kelly-Buabeng/expert-system--illegal-mining-.git
cd expert-system--illegal-mining-

pip install flask


cd frontend
npm install
npm start

```

---

## Usage
1. Open the web application in your browser.
2. Select or enter community-specific environmental data.
3. The backend processes the data through the Prolog rules engine.
4. View pollution risk level and recommendations.
